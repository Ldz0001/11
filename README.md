# Intento Event Planner BI (static front-end)

This bundle is the clean GitHub-Pages-ready version.

## Run locally
- Open `index.html` in a browser, or
- Serve the folder with any static server, e.g.:

```bash
python -m http.server 8000
# then visit http://localhost:8000
```

## Notes
- Data is stored in browser localStorage.
- Vendor catalog can be imported via the Quote Builder (xlsx).
- Backend adaptation can replace localStorage and window.vendorCatalog with API calls later.
